# Contributing to Obsidian SOC

First off, thank you for considering contributing to Obsidian SOC.

## 1. Where do I go from here?

If you've noticed a bug or have a feature request, make sure to check our [Issues](../../issues) tab first. If you don't see it, go ahead and create a new issue.

## 2. Fork & create a branch

If this is something you think you can fix, then fork Obsidian SOC and create a branch with a descriptive name.

## 3. Implement your fix or feature

Make sure your code adheres to our `PRD_Part4.md` guidelines (SOLID, DRY, strict typing).

## 4. Make a Pull Request

At this point, you should switch back to your master branch and make sure it's up to date with Obsidian SOC's main branch. Then, push your feature branch and create a PR.
